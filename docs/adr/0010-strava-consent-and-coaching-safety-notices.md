# Sudolife-owned Strava consent and coaching safety notices

Sudolife will publish its MVP privacy policy in Portuguese and English on a single public page, with Portuguese first and English below, and will show its own Strava data consent before redirecting a user to Strava OAuth, instead of relying on OAuth alone to explain how imported activity data is used inside adaptive coaching. That consent will name the imported data groups, including athlete profile data, recent activities, activity details, performance streams, heart-rate data when available, and heart-rate zones when available. Sudolife will also show recurring coaching safety notices at coaching decision points, but not during account creation or generic onboarding, to keep the warning close to the recommendation without adding unrelated signup friction.

Imported Strava data and other coaching input data may be used to generate recommendations for the same user, but not to train models. This adds a small amount of friction before Strava connection and coaching actions, but makes privacy and safety expectations explicit in the places where users are about to share Strava data or act on coaching output.

Strava data consent is blocking only when the user does not have a consent record for the current consent version. Sudolife will persist a consent record with the user, consent purpose, consent version, language, timestamp, and source before redirecting, so future audits can distinguish explicit Sudolife consent from Strava's OAuth authorization. The initial consent version is `strava-data-import-and-coaching-v1`; when the current consent version changes, the next Strava connection, reconnection, or permission upgrade must require a new explicit confirmation.

For the MVP, account deletion confirmation will be shown on screen after the deletion succeeds. E-mail confirmation is deferred until Sudolife has an e-mail delivery capability, even though e-mail would provide a stronger durable confirmation for the user.
